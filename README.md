# 大积分助手 · BiliPoints

面向 B 站大会员的 Android 积分管理与任务辅助工具。支持 Android 8.0 及以上，开发者：π。

[下载最新版](https://github.com/lyz10-26/BiliPoints/releases/latest) · [更新记录](https://github.com/lyz10-26/BiliPoints/releases) · [安装包校验值](SHA256SUMS)

## 功能

- 同步头像、等级、会员状态、有效期、硬币与可用大积分。
- 展示月度积分进度，辅助签到与浏览任务，核验实际到账结果。
- 展示大会员兑换商品、积分价格、库存与开售时间，确认后显示官方订单结果。
- 在账号菜单检查更新；版本一致时显示“已经是最新版”。

## 使用

1. 安装 Release 页面中的 APK，可覆盖安装此前的同签名版本。
2. 点击右上角「账号」，在 B 站官方页面登录，返回后同步资料。
3. 点击「一键执行并核验」或选择单项任务；兑换前确认商品及消耗积分。

任务中可点击「停止执行」。兑换显示“待确认”时，请先核验订单，避免重复操作。

## 构建

使用 Android Studio，或准备 JDK 17、Android SDK 35、Gradle 8.9 后运行：

```sh
gradle :app:assembleDebug
```

GitHub Actions 可生成调试包。调试包与 Release APK 的签名不同，覆盖安装请使用 Release APK。

## 说明

- 非哔哩哔哩官方应用，任务、积分与兑换结果以官方服务端为准。
- 登录会话保存在本机，可在账号菜单退出；仓库不包含账号凭据和签名私钥。
- 不同浏览任务最多 3 项并行；同类任务按顺序执行，提交请求串行，到账按各项积分记录核验。
- 浏览需保持应用前台，任务与积分到账受官方服务端规则影响。
- 已通过编译与签名检查，尚未完成真机并行浏览、兑换及积分到账的完整验收。
