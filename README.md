# BiliPoints

面向哔哩哔哩大会员的 Android 积分管理与任务辅助工具。

## 当前版本

**1.1.5-release** · versionCode 25

[下载 1.1.5 APK](https://github.com/lyz10-26/BiliPoints/raw/refs/heads/main/BiliPoints-1.1.5-release.apk)

Android 8.0（API 26）及以上版本可安装。

## 功能

- 同步账号资料、会员状态及大积分。
- 查看积分进度，辅助执行签到和浏览任务。
- 展示装扮商城商品、积分价格及库存。
- 兑换后查询订单状态，避免重复操作。

## 构建

需要 JDK 17、Android SDK 35 和 Gradle 8.9：

```sh
gradle :app:assembleDebug
```

## 说明

本项目为第三方工具，非哔哩哔哩官方应用。任务执行、积分到账及兑换结果以官方服务端返回为准。请勿将账号凭据或签名私钥提交到仓库。
